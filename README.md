# iproc

Underwater image color-restoration and enhancement algorithm implementations: DCP,
GBdehazingRCorrection, IBLA, LowComplexityDCP, MIP, MIX, MSF, NewOpticalModel, RoWS, UDCP, ULAP
(color restoration) and CLAHE, GC, HE, ICM, RGHS, RayleighDistribution, UCM (enhancement).

Extracted from `UnderwaterObservserApp/src/main/libs/iproc/`, where it originated as vendored,
in-tree code. Selected and invoked via `ImagesPreprocessorFactory`.
